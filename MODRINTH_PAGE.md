## Description

Everyone is a bean now.

Beanify removes the arms and sleeves from every player model and locks their legs in place, so everybody just slides around like a little bean. The item in someone's hand is still drawn exactly where it should be, and chestplates lose their armor arms too.

- Works on every player, including you in third person and other players on any server
- Client-side only: nothing to install on the server, no config
- Zombies, skeletons and armor stands are left alone
- No dependencies (Fabric API not needed)

It is purely visual. It does **not** add any gameplay change, and it is not a performance mod: expect no measurable FPS difference.

If a future Minecraft update changes the player model, Beanify quietly does nothing instead of crashing.
